# PR Review

## PR description template
## What changed / Why / Verification (real output) / Not verified

## Reviewer checklist
- [ ] Diff small enough to read carefully in one sitting.
- [ ] Every "Verification" claim has real, pasted output behind it.
- [ ] Tests actually test the linked spec's acceptance criteria.
- [ ] No hard rule from AGENTS.md §1 was violated.
- [ ] Anything marked "human decides" in AGENTS.md §3 got an actual human decision.
